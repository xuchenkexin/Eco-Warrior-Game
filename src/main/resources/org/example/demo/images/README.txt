# Game Background Images

To enable custom backgrounds for each level, please add the following image files to this folder:

1. `background.png` - Default game background
2. `player.png` - Player character sprite
3. `polluted_bay_bg.png` - Level 1 (Polluted Bay) background
4. `rusty_city_bg.png` - Level 2 (Rusty City) background
5. `suffocating_forest_bg.png` - Level 3 (Suffocating Forest) background
6. `sacred_mountain_bg.png` - Level 4 (Sacred Mountain) background

## Recommended Image Specifications

- Resolution: 800x600 pixels or higher
- Format: PNG with transparency support
- File Size: Keep under 2MB per image for better performance

## Background Image Suggestions

### polluted_bay_bg.png
A polluted beach with plastic waste, oil barrels, and dead marine life washed ashore. The water should appear dark and contaminated, with a gloomy sky overhead.

### rusty_city_bg.png
An industrial cityscape with factories emitting dark smoke, rusty structures, and a polluted river running through it. The sky should be smoggy and gray.

### suffocating_forest_bg.png
A deforested area with withered trees, tree stumps, and brown vegetation. Some areas should look scorched or damaged.

### sacred_mountain_bg.png
A mystical mountain peak with ancient stone structures, some small altars, and a clearer sky. This area should look less polluted than the others but still show signs of litter.

Please create the following image files and place them in this directory.
The game will automatically load them based on the item names defined in the levels.
Ensure the filenames are in lowercase and spaces are replaced with underscores (_).
